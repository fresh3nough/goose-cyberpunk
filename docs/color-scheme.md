# Neon Cyberpunk Color Scheme

| Role | Color | Hex | Notes |
|------|-------|-----|-------|
| Background (void) | deep indigo-black | `#07070f` | Main app chrome |
| Surface | panel | `#0e0e1a` / `#16162a` | Cards, sidebar, inputs |
| User input text | neon pink | `#ff9aef` | Chat textarea caret + typed text |
| User messages | hot magenta | `#ff4fd8` | User bubbles, glow border `#ff00aa` |
| AI responses | electric cyan | `#7df9ff` | Assistant bubbles + headings |
| Terminal / code | matrix lime | `#39ff14` | `pre`, `code`, syntax blocks |
| Primary text | ice | `#e8f6ff` | Body UI text |
| Secondary text | steel cyan | `#8ab4c8` | Muted labels |
| Accent magenta | neon | `#ff00aa` | Borders, rings, selection |
| Accent cyan | neon | `#00e5ff` | Focus, links, AI glow |
| Danger | hot pink-red | `#ff2a6d` | Errors |
| Warning | signal yellow | `#fcee0a` | Warnings |

## Fonts

- **UI:** [Rajdhani](https://fonts.google.com/specimen/Rajdhani) (loaded from Google Fonts)
- **Display / clock / headings:** [Orbitron](https://fonts.google.com/specimen/Orbitron)
- **Mono / terminal:** [Share Tech Mono](https://fonts.google.com/specimen/Share+Tech+Mono)
- Fallbacks: Ubuntu / Noto Sans / system UI, Ubuntu Mono / DejaVu Sans Mono

Text sizes are bumped ~1 step above Goose defaults (`text-sm` → 1rem, base body 17px).
